# 从学生的角度阅读语法

面向日语母语的初级汉语学习者，语法页按「理解用途 → 看词语顺序 → 听例句 → 换成自己的内容」组织。

- 25 个知识点都有默认可见的学习目标和简短提示，说明何时使用、词语怎么排列。
- 147 条原有朗读内容按肯定、否定、提问，或数字、时间、场景等分组。每条保留拼音、译文与男女声。
- 同课有多个知识点时提供页内跳转；跳转会停止旧音频，避免朗读自动滚动把学生带回上一节。
- 「このポイントを聞く」只播放当前知识点；「この課を全部聞く」播放整课。
- 手机初次打开时收起声音与显示设置，优先展示学习内容；仍可展开调整声音、速度和拼音等。
- 切换声音只更新朗读文字，不重建页面，保留说明展开状态、键盘焦点和阅读位置。点击已选声音不会中断播放。
- 原教材说明和表格保留在每节末尾，作为补充查阅内容。

`grammar-guide.js` 独立保存日语学习提示、词序和分组数量。组的 `count` 按 `voice-data.js` 中该知识点的顺序切分，所有条目必须恰好出现一次。录音、原始例句和教材资料没有改动。

```sh
node tests/study-check.js

```

浏览器套件保留全部 586 段录音及播放设置的回归检查，并增加：25 个知识点 × 2 种声音的独立播放边界、全部 294 条语法录音的组内顺序、完整知识点连续播放、最后一句重播、键盘跳转、手机设置、切换声音保留阅读状态、隐藏拼音和译文。
