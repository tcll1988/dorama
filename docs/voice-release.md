# 男女声录音更新

本版使用用户提供的「女声-会话单词语法.zip」和「男声-会话单词语法.zip」，
各 293 条，共 586 条。文件按交接清单的 ID、台词和路径对应，未重新合成音频。
男声包的说明注明使用普通男老师声音，并非用户的克隆声。

| 内容 | 女声 | 男声 | 使用方式 |
| --- | ---: | ---: | --- |
| 会话 | 32 | 32 | 山本使用女声；王、店员、司机使用男声 |
| 单词 | 114 | 114 | 「音声」设置选择女性或男性 |
| 语法 | 147 | 147 | 「音声」设置选择女性或男性 |

恢复 14 课「文法」页面，保留 25 节原始说明。147 条朗读内容覆盖例句、
表格和时间表达；可选表达拆为独立录音，数字按实际读法显示。
单词和语法共用声音偏好并保存到浏览器。切换声音会停止当前播放，
再次点击播放即使用所选声音；会话始终保留各角色的声音。

`voice-data.js` 保存实际播放路径、SHA-256、时长、逐字时间和语法朗读条目。
录音位于 `audio/female/lessonXX/` 和 `audio/male/lessonXX/`。
高亮使用上传包的逐字时间；会话与单词保留现有词组和拼音，
语法拼音从交接清单按字拆分。所有音频 URL 带内容指纹，避免缓存旧录音。

## 验证

```sh
node tests/study-check.js
CHROMIUM_PATH=/usr/bin/chromium node tests/browser-check.cjs http://127.0.0.1:8001/ /tmp/dorama-browser.json
python3 tools/verify-site.py http://127.0.0.1:8001/ --output /tmp/dorama-site.json
python3 tools/pack-web.py /tmp/dorama-web.zip
```

导入时核对所有文件指纹、清单身份、逐字台词、时间戳顺序和时长，
并完整解码全部 586 个 MP3。

浏览器检查覆盖：

- 42 个本文、单词、语法页面，6 种屏幕尺寸，共 252 种组合；
  展开全部语法说明，检查手机和平板布局。
- 全部 586 个录音的 SHA-256、浏览器解码、实际播放及每个高亮字词的定位。
- 男女声切换、键盘选择、刷新与页面间保存、播放或暂停时切换停止旧音频、
  会话角色不受声音偏好影响。
- 5 档速度、暂停、继续、重播、下一句、关闭，本文和男女声单词/语法连续播放。
- 音频请求失败后的重试、存储不可用、无效保存值、旧链接、帮助框和手机菜单。

`.github/workflows/verify-pages.yml` 在 main 更新后等待 GitHub Pages 发布，
核对 597 个发布文件的指纹，完整解码 586 个音频，并在正式网站运行同一浏览器检查。
运行结果保存在 Actions 的 `dorama-published-verification` 附件中。
功能测试和时间戳核对不等同于对全部发音或音色的人工听辨。

## 维护范围

`course-data.js`、`source/` 和旧录音保留。当前播放器从 `voice-data.js`
取录音路径，不再使用旧 `audio/lessonXX/` 路径。
旧 `tools/import-audio.py` 只维护旧格式，不适用于这批男女声包。
修改新录音时必须同步更新对应声音的字词时间、时长、SHA-256 和 `audioVersion`。

既有 `tools/build-course.py` / `tests/edit-check.py` 仍引用 161 个缺失的旧
文法/练习音频，不能作为本版本的完整发布检查。新文法页面使用独立的新录音；
练习页继续隐藏。本次没有重建 `course-data.js`，上述旧资源缺失不影响已发布页面。
