════════════════════════════════════════
 改 config.js 的注意事项
════════════════════════════════════════

 · 只改引号 ' ' 里面的文字，不要删引号、逗号、括号。
 · {n}、{title}、{total}、{word}、{speed} 是占位符，页面会自动换成课号等，请保留。
 · 改完如果页面变成空白，多半是少了引号或逗号。可以执行下面的检查命令，它会指出问题：
       node tests/study-check.js


════════════════════════════════════════
 改课文（source/*.json）
════════════════════════════════════════

 维护者每次只改一课。要改某一句会话的日语译文，只打开那一课的文件，改那一句的 jp。
 改完后，在含有 index.html 的这个文件夹里执行一步：

     py -3 tools/build-course.py

 页面读到的就是这一步生成的 course-data.js。其他课保持不动，这一句原来的音频文件仍然有效。

 课文 JSON 里的 grammar、exercises 数据仍然保留，build-course.py 照常打包，
 但页面已不显示「文法」「練習」。旧链接 #lesson/N/grammar、#lesson/N/practice…
 会自动跳到该课的本文页面。

 某句没有录音时（audio 为空），页面会标出「教材音声なし」。
 materials 文件夹是原始教材，供查阅，页面不从那里取播放路径。


════════════════════════════════════════
 更换录音
════════════════════════════════════════

 本文・单词的录音放在 audio/lesson01～lesson14/：
     reading-03.mp3 = 该课本文第3句      word-08.mp3 = 该课第8个单词
 （audio/clips/ 里是原教材录音，课文数据里的语法・练习部分还引用它们，请不要删。）

 ■ 整批更换
     py -3 tools/import-audio.py 音频包文件夹
   音频包文件夹里要有 manifest.json（格式同 textbook-audio 音频包）。
   工具按「课号 + 中文」自动对应，一条录音含连续几句时按停顿自动切开，
   同时重新计算逐字高亮时间并生成 course-data.js。

 ■ 补录几句（推荐：以后只重录个别句子时用这个）
   把 mp3 放进一个新文件夹，文件名写成那句中文，例如「你要几个？.mp3」，然后执行
     py -3 tools/import-audio.py 这个文件夹
   · 文件名只在一处出现的句子・单词会直接替换。
   · 一句由几段录音组成时（如「你好！.mp3」「一百块.mp3」「你要几个？.mp3」），自动按顺序接成一句。
   · 「你好！」这种好几课都有的文字，不会被单独拿去替换别处。

 结果（换了哪些、没用上哪些）写在 audio/import-report.txt。没对上的句子保留现有录音。
 需要电脑上装有 ffmpeg。

 ■ 只换一个文件
   用同名 mp3 覆盖 audio/lessonXX/ 里的文件即可（例如重录第7课第8个单词 → 覆盖 word-08.mp3）。
   逐字高亮的时间不会自动更新；想要更新，就把这个文件和 manifest.json 放进音频包，重新整批执行一次。

 现在本文・单词全部使用新录音（audio/lessonXX/）。


════════════════════════════════════════
 给学生用：电脑 / 手机・平板
════════════════════════════════════════

 电脑：把整个 ZIP 解压后，用 Edge 或 Chrome 打开 index.html。不需要安装、账号或联网。

 手机・平板：手机无法直接打开 ZIP 里的 index.html，需要放到网站上，让学生用网址打开。
   1. 执行   py -3 tools/pack-web.py drama-web.zip
      生成只含页面所需文件的精简包（约 2 MB，不含 materials 等原始教材）。
   2. 解压后把 drama-web 文件夹整个上传到网站（大学服务器、GitHub Pages 等）。
   3. 把 index.html 的网址（或二维码）发给学生。
      iPhone：Safari「共有」→「ホーム画面に追加」；Android：Chrome「︙」→「ホーム画面に追加」，
      就能像 App 一样从桌面图标打开。

 电脑版 ZIP 用这个命令打包（含 materials 原始教材）：
     py -3 tools/pack-learner-zip.py drama-chinese-beginner-ready.zip
